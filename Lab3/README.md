# Лабораторная работа №3 — Токенизация текста

Проект на C# для разделения текста на предложения и токены, сортировки предложений, поиска и замены слов, удаления стоп-слов и экспорта результата в XML.

Запуск:

```bash
dotnet run --project lab3.csproj
```

Тесты: в `Program.cs` можно временно раскомментировать `Lab3Tests.RunAll();` и `return;`.
