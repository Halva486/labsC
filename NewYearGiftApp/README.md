# Новогодний подарок

Учебное консольное приложение на C# для формирования новогоднего подарка из шоколадных и карамельных конфет.

## Возможности

- добавление конфет в подарок;
- подсчёт общего веса;
- сортировка конфет по весу по возрастанию;
- поиск конфет по диапазону содержания сахара;
- получение описания типа конфеты с использованием полиморфизма.

## Структура проекта

- `Sweet.cs` — абстрактный базовый класс сладости;
- `ChocolateCandy.cs` — класс шоколадной конфеты;
- `CaramelCandy.cs` — класс карамельной конфеты;
- `IGift.cs` — интерфейс операций с подарком;
- `NewYearGift.cs` — реализация управления набором конфет;
- `Program.cs` — пример использования приложения;
- `Tests/GiftTests.cs` — шесть модульных тестов на xUnit.

## Требования

- .NET 10 SDK

## Запуск приложения

Из папки `NewYearGiftApp`:

```bash
dotnet run
```

## Запуск тестов

Из папки `NewYearGiftApp/Tests`:

```bash
dotnet test
```

Тесты проверяют добавление конфет, общий вес (в том числе пустого подарка), сортировку, поиск по содержанию сахара и полиморфизм.
