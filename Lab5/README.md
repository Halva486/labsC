# Lab5 — Авиакомпания

Консольное приложение на C# для управления авиапарком. Проект демонстрирует наследование, абстрактные классы, полиморфизм, пользовательские и стандартные интерфейсы.

## Требования

- .NET 8 SDK
- Visual Studio 2022 или другая среда с поддержкой .NET 8

## Структура проекта

- `Models/Aircraft.cs` — абстрактный базовый класс самолёта.
- `Models/PassengerAircraft.cs` — пассажирский самолёт.
- `Models/CargoAircraft.cs` — грузовой самолёт.
- `Models/MixedAircraft.cs` — комбинированный самолёт.
- `Interfaces/IAircraftSearch.cs` — интерфейс поиска самолётов.
- `Services/Airline.cs` — класс авиакомпании и операции с авиапарком.
- `Tests.cs` — автоматические проверки функциональности.
- `Program.cs` — точка входа приложения.

## Реализованные возможности

- Добавление самолётов разных типов.
- Вывод информации о самолётах.
- Подсчёт общей пассажировместимости и грузоподъёмности.
- Сортировка самолётов по дальности полёта через `IComparable<Aircraft>`.
- Поиск по диапазону расхода топлива через `IAircraftSearch`.
- Проверка входных данных в конструкторах.
- Демонстрация полиморфизма и запуск тестов.

## Запуск

Из каталога `Lab5` выполните:

```bash
dotnet build
dotnet run
```

В программе создаётся авиакомпания «Аэрофлот» с несколькими самолётами, демонстрируются операции с авиапарком и запускаются автоматические проверки.
